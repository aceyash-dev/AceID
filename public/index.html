Identity

What is Ace ID?

Ace ID is The Ace Base's identity and authentication platform for Ace ID sign-in, profile control, sessions, security settings, and connected applications.

Security

How does it protect accounts?

It supports passkeys, TOTP MFA, recovery codes, session control, activity, and protected OAuth 2.0 / OpenID Connect flows.

Integration

What protocol does it use?

Ace ID is an OpenID Connect identity provider using OAuth 2.0 Authorization Code flows and PKCE-ready clients.

Operator

Who operates Ace ID?

Ace ID is operated by The Ace Base as the identity layer for its connected services and applications.
