# Ace ID for Android

The Flutter Android account client for Ace ID, a product of **The Ace Base**. It supports account access, profile management, security activity, devices and sessions, connected apps, and subscription views.

This directory contains the Android app source. Detailed architecture, OpenID Connect configuration, build and CI instructions, and known limitations belong in [ACE-DOCS](https://docs.ace-base.cc).

The app uses a public OIDC client ID. Never embed a client secret or backend credentials in the client application.
